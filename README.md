## 🎧 Next-Gen Headphones — Apple-Style Product Landing Page

A sleek, ultra-modern landing page for high-end wireless headphones inspired by Apple's minimalist design language. Built with dark mode aesthetics, high-contrast typography, and smooth interactive elements.

🌐 **Live Demo:** [https://your-site-link-here.com](https://bolt.new/p/71515890)

## ✨ Features

- **Apple Aesthetic**: Premium dark theme with `San Francisco` style typography and minimalist layouts.
- **Interactive Color Selector**: Switch between custom finish options with live visual previews.
- **Bento Grid Highlights**: Showcasing key specs like Active Noise Cancellation, Spatial Audio, Chip performance, and Battery life.
- **Interactive Buy/Pre-order Modal**: Smooth overlay for selecting configurations and completing pre-orders.
- **Fully Responsive**: Flawless display across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic layout & accessibility
- **CSS3** — CSS Variables, Grid/Flexbox layouts, smooth transitions & animations
- **JavaScript (ES6+)** — Interactive DOM updates & modal logic
- **Vite** — Fast frontend build tool
