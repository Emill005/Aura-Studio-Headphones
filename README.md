# ☕ AURA Coffee — Modern Specialty Coffee Landing Page

A sleek, vibrant, and fully responsive single-page website for a specialty coffee shop built with modern web technologies.

---

## ✨ Features

- **Interactive Menu Filter**: Smooth category switching for Coffee, Signature Drinks, and Desserts.
- **Table Booking Modal**: Interactive reservation form with seamless pop-up animations.
- **Modern UI/UX**: Bold typography (`Unbounded` & `Plus Jakarta Sans`) with a fresh, high-contrast palette.
- **Mobile-First & Responsive**: Optimized for desktop, tablet, and smartphone screens.

---

## 🛠️ Built With

- **HTML5** — Semantic layout & accessibility
- **CSS3** — Custom properties, CSS Grid/Flexbox, smooth animations
- **JavaScript (ES6+)** — Interactive DOM manipulation
- **Vite** — Fast frontend development & bundling
